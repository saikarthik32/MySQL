SET OPERATORS
1.Union:
combine results from two queries and remove duplicate rows.column must be have the same number and type.

2.Union All:
combine results from two queries and include all rows. including duplicates.columnmust have the same number and type.

3.INTERSECT:
returns rows that are common to both quries.column must have tha same number and type.
note:MySQL doesn't support intersect directly.

4.Minus/Except:
returns rows from the first query that are not present in the second query.column must have the same number and type.

JOINS
A Join in MySQL is used to combine rows from two or moretables based on related column.
Example:
employees tables--> employee details.
department table--> department details.
 
if you wany to see which employees belongings to which department. you need to join these two tables.

Why do we need joins?
1.to fetch data from multiple tables in a single query.
2.to reduce data duplication(instead of keeping everything in one table).
3.to implement relationships like(one-to-one,one-to-many,many-to-many,many-to-one).
4.to generate reports and analtics combine diff datasets.

types of joins:
1.inner join:
retruns only the row that have matching values in both tables.
syntax:
select columns
from table1
inner join table2
on table1.common_column2.common_column;

2.right join:
returns all rows from the right table and the matched row from the left table if no match null values appear for the left table columns.
syntax:
select coulumns
from table1
right join table2
ontable1.common_column=table2.common_column;

3.left join:
returns all rows from the left table and the matched row from the right table if no match null values appear for the right table columns.
syntax:
select coulumns
from table1
left join table2
ontable1.common_column=table2.common_column;

4.full join:
to simulte the use the union of left join and right join.
syntax:
select coulumns
from table1
left join table2
ontable1.common_column=table2.common_column;
union
select coulumns
from table1
right join table2
ontable1.common_column=table2.common_column;

5.cross join:
returns cartesian product-->every row from the first table with every row from the second table.
syntax:
select columns
from table1
cross join table2;

6.self join:
a table joined with itself.
syntax:
select a.columns,b.columns
from table1 a
inner join table1 b
on a.commn=b.common_column;
