Numeric Functios
1.abs(): absolute value of a number
2.ceil(): round up
3.floor(): round down
4.round(): round to a specific number of digits
5.mod(): module of a number
6.pow()/power(): exponentiation
7.sqrt(): square root
8.exp(): exponentional functio
9.radians(): convert degrees to radians
10.degrees(): convert radinas to degrees
11.sign(): returns the sign of a number
12.rand(): generate a random number
13.greatest(): find the maximum value
14.least(): find the minimum value
15.pi(): return the value of p
16.hex(): convert to hexadecimal
17.oct(): convert to octal
18.bin(): convert to binary
